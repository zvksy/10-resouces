# 10HUB — Class 10 Study Hub

A dark, modern, database-ready resource directory for CBSE Class 10.

## Current version
- Dark responsive UI
- Subject cards
- Resource directory
- Search
- Resource-type filters
- Local bookmarks
- Local profile name
- Seed data separated from UI

## Next backend upgrade
Connect Supabase for:
- Authentication
- Student profiles
- Bookmarks
- Chapter progress
- Resource database
- Admin resource management

## Deploy
This version is plain HTML/CSS/JavaScript and can be deployed directly to Vercel from GitHub.
